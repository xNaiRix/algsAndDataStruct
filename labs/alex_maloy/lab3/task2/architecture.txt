Архитектура проекта модульная:
-заголовки для каждого файла с логикой
-отдельные .cpp файлы с логикой (к соответствующим заголовкам)
-файл main.cpp для запуска проекта в консольном режиме
-файл tests.cpp для запуска тестов
-CMakeLists.txt для легкой сборки и запуска проекта 

В файле tests.cpp:
- обязательно прогоняются все примеры из задания. Выводятся при этом входные данные, выходные данные программы, ожидаемые выходные данные и есть ли расхождения. В каких местах расхождения
- ОБЯЗАТЕЛЬНО и другие тесты на проверку логики работы
- Все логи тестирования должны быть читаемыми и понятными (чтобы с одного быстрого прочтения можно было легко понять, какая в целом логика реализована, какая работает и проходит тесты, а какая - нет)

сборка:
- она должна происходить с помощью встроенной в vs code утилиты run tasks - там выбрать cmake build / cmake run 
- не забудь настроить tasks.json, чтобы можно было легко всё билдить и запускать!
основная логика:
- хорошая архитектура файлов
- все декомпозировано
- принципы SOLID
