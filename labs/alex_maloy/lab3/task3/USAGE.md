# Как пользоваться программой

## Краткий экскурс

Это симуляция экономики городка с банком и набором персонажей: Homer, Marge, Bart, Lisa, Apu, Burns и бонусными участниками.
Система моделирует банковские счета, наличные, депозиты, снятие, внутренние переводы и поведение участников в течение нескольких шагов.

Программа имеет два режима:
- `economy` — запускает симуляцию
- `tests` — запускает набор юнит-тестов

## Запуск программы

### Сборка проекта

1. Откройте каталог проекта в VS Code.
2. Запустите задачу `CMake: Build` через меню `Terminal -> Run Task...`.
3. Если нужно, выполните `CMake: Configure` перед сборкой.

### Запуск симуляции

В командной строке из корня проекта выполните:

```powershell
cmake --build build --target economy --config Debug
build\Debug\economy.exe [NUM_ITERATIONS]
```

Если `NUM_ITERATIONS` не указан, приложение запросит число итераций через ввод с клавиатуры.

### Примеры

- Запустить 10 шагов симуляции:

```powershell
build\Debug\economy.exe 10
```

- Запустить с вводом значения вручную:

```powershell
build\Debug\economy.exe
```

После запуска программа выведет диагностические сообщения о действиях участников на каждом шаге и итоговую проверку согласованности системы.

## Запуск тестов

1. Соберите проект с помощью CMake (`CMake: Build`).
2. Запустите тестовый исполняемый файл:

```powershell
build\Debug\tests.exe
```

Это выведет подробный отчет по всем юнит-тестам, включая проверку:
- работы банка,
- операций с счетами,
- переводов,
- обработки исключений,
- экономической модели.

## Что вводить

- В консоли можно запускать только один аргумент: количество итераций.
- Число итераций должно быть неотрицательным целым.
- Если аргумент не передан, приложение запросит его через stdin.

## Детали работы

- `economy.exe` моделирует поведение персонажей по шагам.
- В конце выводится:
  - сумма наличных участников,
  - сумма денег на счетах,
  - подтверждение общей сохранности денег.

- `tests.exe` проверяет реализацию `Bank` и модель поведения акторов. Он должен завершаться с кодом `0`, если все тесты пройдены.
